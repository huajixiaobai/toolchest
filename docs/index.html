它能做什么

① 图鉴与搜索
527 个条目 · 27 个分类 · 5 种语言

按分类浏览，按 ID / 名称 / 描述 / 数值 / 图集坐标搜索；cat:Joker rarity:1 cost>=4 这种字段筛选也能用。

② 卡牌合成台（可以点）

选一张牌，叠加强化 / 蜡封 / 贴纸 / 版本。版本特效是游戏自己的 GLSL 在浏览器里跑，不是画的假效果。

③ 导出（PNG 可以点）
点一下 PNG：会下载一张由代码画出来的示例（1x–6x 与透明背景都是真的）

单张导出 PNG / SVG / ZIP / JSON / CSV / Markdown；盲注动画还能导出 GIF、APNG、帧序列。

④ 图集切分 · 逐帧动画 · 自动找循环点

左边：一张图集被切成格子，逐格取出（真实数据里就是 68 张贴图 / 69 个图集）。右边：21 帧的盲注动画循环播放，程序会算出「接缝最小」的那一帧当循环点，导出的动图才不会跳。

上面全是代码画的示意（这个站里没有任何游戏素材）；真实内容来自你自己电脑上的那份游戏文件。

这个站在做什么

这里放的都是「本地工具」：它们不托管任何游戏素材，而是把你自己电脑上那份游戏里的美术与数据读出来，变成能搜索、能预览、能导出的东西。

  • 素材不会上传：解析在浏览器内完成，结果只留在内存里，关掉页面就没了。
  • 站点本身不含任何游戏素材或游戏数据，只含代码。
  • 带素材的「单文件离线版」不提供公开下载（那等于分发游戏资源）；需要的话可以照仓库里的说明自己构建。
  • 本站是非官方粉丝作品，与 LocalThunk / Playstack 没有任何关联；游戏素材与数据的版权归原作者所有。
